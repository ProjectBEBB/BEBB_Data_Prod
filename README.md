# BEBB Editionsdaten 1.0.0-beta

Dies ist der unveraenderliche Datenstand des beta-Releases
der Basler Edition der Bernoulli-Briefwechsel (BEBB).

- Version: `1.0.0-beta`
- Publikationsdatum: `2026-11-20`
- Versions-DOI: `10.5281/zenodo.24166103`
- Lizenz der BEBB-Editionsdaten: CC BY-SA 4.0; siehe `data/LICENSE`

Das Paket enthaelt TEI-XML, freigegebene Figuren und Richtlinienbeispiele sowie
das zum Release gehoerende ODD, Relax-NG-Schema und die Entitaetendeklarationen.
Portraets, sonstige Bildarbeitsdaten, interne Skripte und Office-/Oxygen-Dateien
sind nicht Bestandteil dieses Datenpakets.

Quellcommits, Dateipruefsummen und technische Artefakte sind in
`release-manifest.json` dokumentiert. `SHA256SUMS` prueft den Paketinhalt.

Versions-DOI. Die Lizenz gilt für die BEBB-eigenen Editionsdaten, soweit nicht
