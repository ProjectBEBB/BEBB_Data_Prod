# BEBB_Data_Prod

Release repository for the Basler Edition der Bernoulli-Briefwechsel (BEBB).

This repository provides reviewed, stable publication assets used by the
edition. Working files, tests, detailed technical documentation, and editorial
guidelines are maintained in `BEBB_Data_WIP`. Files are transferred here only
after review and validation.

The repository is intended as a publication and distribution target, not as
the primary workspace for ongoing development.
